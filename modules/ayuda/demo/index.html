// Sketch de ejemplo · parpadeo del LED integrado
// Proyecto: ESP32 IDE · Seminario de Integración

const int LED = 2;

void setup() {
  Serial.begin(115200);
  pinMode(LED, OUTPUT);
  Serial.println("ESP32 IDE listo");
}

void loop() {
  digitalWrite(LED, HIGH);
  delay(1000);
  digitalWrite(LED, LOW);
  delay(1000);
}

Preguntas frecuentes
Solución de problemas y dudas del IDE
1El IDE no detecta mi placa ESP32 (no aparece el puerto COM). ¿Qué hago?

Normalmente falta el controlador USB-UART del sistema operativo. Identifica el chip serial de tu placa (los más comunes son CP2102 y CH340) e instala el driver oficial. Después reinicia el IDE y revisa Herramientas › Puerto para seleccionar el puerto correcto.

Descargar drivers CP210x
2Al subir el código aparece: «A fatal error occurred: Failed to connect to ESP32».

La placa no entró en modo de programación. Pulsa «Subir» en el IDE y, cuando la consola muestre «Connecting...», mantén presionado el botón BOOT (o FLASH) de la placa hasta que aparezca el porcentaje de carga. Suelta el botón al terminar.

Solución de problemas de esptool
3¿Cómo instalo librerías externas para mis sensores?

Abre el gestor de librerías del IDE y busca el componente que necesitas (por ejemplo, un driver para un sensor DHT11 o una pantalla OLED SSD1306). Elige la versión compatible y pulsa Instalar; quedará disponible para todos tus sketches.

Guía del gestor de componentes
4¿Por qué el monitor serie muestra caracteres extraños?

La velocidad del monitor no coincide con la de tu sketch. Revisa la instrucción Serial.begin(115200); y ajusta el selector de baudios de la esquina inferior derecha del monitor exactamente al mismo valor.

5¿Cómo selecciono la placa y la velocidad de carga?

En la barra superior usa el selector de placa (por ejemplo ESP32-S31 Dev Module) y el selector de puerto. Para la velocidad de carga abre Herramientas › Velocidad de carga y elige 921600 baudios; si la carga falla, baja a 115200.

6¿Dónde reporto un error o sugiero una mejora?

Registra el problema en el repositorio del proyecto con el formato de reporte de bugs: describe los pasos para reproducirlo, la versión del IDE y el mensaje de la consola. Así el equipo de QA puede dar seguimiento.
